# Top-Scout
Project Repo for The Doers

## Description
***Top Scout*** is a project management application designed for Boy Scouts beginning their journey towards becoming an Eagle Scout! Our app acts as a guide for the Eagle Scout workbook, which contains a number of documents that a scout is required to complete before ranking up to Eagle. With Top Scout, scouts can keep all of these documents in one organized virtual space that visually tracks their progress as they continue working on tasks. 

The idea and motivation for this kind of app comes from our own teammate Simon's experience as a Boy Scout. He found that managing all of the documents and tasks that are required working through the Eagle workbook became a real challenge. Now, thanks to Top Scout, scouts can easily view and manage their organized documents and make their way to the Eagle rank!
